# xagent Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Claude Code mod (`xagent`) that dispatches tasks to the Codex, Copilot and Antigravity CLIs and routes each task by quota and complexity. A skill (`cross-model-dev`) then uses it to run plan review → routing → implement → review.

**Architecture:**
- Pure modules hold the logic and are unit-tested: argv building, event parsing, quota math, and the routing config and clamp.
- Atoms are declared in each file that uses them (the engine's state scan requires it).
- `io.ts` reads quota and git trees from the host.
- `register.ts` wires everything to the mod API: tools, spawn and `turn.step`.
- A patched agent-radar and a patched mission-control read the `xagent.agents` atom.
- The skill is markdown that tells Opus how to use the two tools.

**Tech Stack:**
- Claude Code mod API (`claude-code`, `claude-code/testing`), TypeScript.
- Tests: `claude plugin test` (bun). Type check: `tsc` through `npx`.
- CLIs: `codex` 0.162.1, `copilot` 1.0.x, `agy`, `sqlite3`, `git`.

**Spec:** `docs/specs/2026-10-14-xagent-design.md`

**Checked 2026-10-14:** the plan's code, assembled into a scratch mod, passes `tsc --noEmit` (strict, `noUncheckedIndexedAccess`), `claude plugin validate` and all 58 tests. The Task 7 radar patch and its tests pass on a scratch copy of agent-radar, and the new tests fail without the patch. Code that differs from the plan is a bug in one or the other: stop and say which.

## Global Constraints

- No API keys. Every backend runs on its CLI's subscription login.
- Commands run by argv through `$.process.spawn` or `$.process.run`, never as a shell string.
- Only a short summary of an external run enters Claude's context. Transcripts stay in each CLI's store.
- **Copilot:**
  - Student plan: auto model only, so never pass `--model`.
  - 200 AI credits a month, resetting 00:00 UTC on the 1st.
  - Never used for plan review, because it has no read-only mode.
- A provider at or above 90 % of a quota window that has not reset yet gets no new work, unless the user overrides.
- **Defaults:**
  - Plan review: codex / gpt-6.1-sol / high.
  - Implementer: codex / gpt-6.1-sol.
  - Reviewer: Sonnet, or Haiku for trivial tasks.
  - Router: codex / gpt-6-luna / low.
- User instructions override routing and the clamp.
- **Time:** every time value in mod code comes from `await $.clock.now()`, never `Date.now()`. Tests drive it with `mock.clock`.
- **The gate:** a task is done when both of these pass from `mods/xagent`:
  - `claude plugin test .`
  - `npx -y -p typescript@5.9.3 tsc --noEmit -p .`
  - The generated tsconfig includes `hooks/`, `types/` and `tests/` with `strict` and `noUncheckedIndexedAccess`. On 2026-10-14 this was checked on `mods/hud`: the command passes there and catches an unchecked index.
  - `claude plugin test` takes a mod directory, never a test file.
- **Commits:** one line, no AI attribution trailers. Every commit and push needs the user's yes (rulebook `confirm-commit-push`).
- The mod lives at `mods/xagent/`. `install.sh` picks it up from `mods/` with no change.

## Spec corrections found while planning and in Sol's review

The spec is updated to match each of these:

- **Codex quota:** `codex exec --json` does not emit `rate_limits`. They are in the rollout files (`~/.codex/sessions/YYYY/MM/DD/rollout-*.jsonl`, `event_msg` payload `type: token_count`).
- **Copilot quota:**
  - It is the sum of `total_nano_aiu` in `~/.copilot/session-store.db` (`assistant_usage_events`) for rows whose `created_at` falls in the current UTC month. The db is opened read-only.
  - This counts interactive and xagent CLI use on this machine, but not VS Code or web use.
  - Credits = nano AIU / 1e9. This conversion is unverified; Task 11 checks it against `/usage`.
  - The multiplier extraction is dropped, because the Student plan is auto-only.
- **Stale quota:**
  - A window whose reset time has passed no longer counts.
  - A window with no reset time has no pace.
  - A cooldown mark that has expired gives way to the live reading.
- **Timeout and retry:**
  - The dispatch tool owns the single timeout retry and reports `attempts`.
  - It retries only once the child is confirmed stopped.
  - When a session id was seen, the retry resumes that session. Otherwise it starts again.
- **Structured answers:** with a schema, the full answer (up to 200 000 chars) is returned as `answer` and must parse as JSON. Only `summary` is capped at 4 000 chars.
- **Dispatch result:** `filesChanged`, `baseTree`, `tree` and `quota` are all in it. Trees are taken through a scratch index (`GIT_INDEX_FILE`), so the user's index is untouched.
- **routing.md:** its fenced `json` block is executable config (router, bands). The rest is advisory text for Luna.
- **Router isolation:**
  - The router runs in an empty directory with no repo text in its prompt.
  - Codex's read-only sandbox can still read files by absolute path. The spec accepts this.
- **Reviewer effort:** the Agent tool has an `effort` field, to be set when instructions (here, the skill) ask for a level. The skill passes the pick's reviewer effort there; no mod code is needed. Task 11 checks that it takes effect.
- **The 90 % rule is enforced, not advised:** `dispatch` refuses a blocked backend unless `override: true`, and `route` returns `wait` when no implementer or the Claude reviewer is free. The skill sets `override` only when the user allows it.
- **Lost baseline:** a write run in a repo whose first snapshot fails never starts; any later `treeError` stops review for that task.
- **Native subagent area:** no render component exists for it. Task 9 probes `Spinner`.

## Review Focus

1. **A dispatch that runs long or never speaks.**
   - Expected: it stops at `timeoutMs`; the child is confirmed stopped before one retry; and the result says `attempts`.
   - Tests (Task 5): `a silent child is stopped and retried once`, `a child that will not stop is reported, not retried`, `a timeout after a session id resumes it`.
   - Task 11 checks that the real child is gone (`pgrep`).
2. **CLI not logged in or not installed.**
   - Expected: `ok: false` within seconds, and the provider is marked unavailable.
   - Tests (Task 5): `a logged-out CLI is marked unavailable`, `spawn failure marks the backend unavailable`.
3. **Luna returns junk, wrong enums or a bogus backend.**
   - Expected: band defaults, with `why` saying so.
   - Tests (Task 6): `bad router output falls back to defaults`, `a bogus backend falls back, not crashes`.
4. **Stale or missing quota data**, on a fresh machine, after a reset, or once a cooldown has expired.
   - Expected: the provider is not blocked by old numbers.
   - Tests (Task 4): `missing data is unknown, not blocked`, `a window past its reset no longer blocks`, `an expired cooldown gives way to live data`.
5. **Huge output or a long structured answer.**
   - Expected: `summary` is capped; a schema answer comes back whole and valid, or as an explicit failure.
   - Tests (Task 3): `summary is capped`, `a long structured answer is kept whole`, `a structured answer that is not JSON fails`.

`mods/xagent/types/index.d.ts`:
```ts
export type Backend = 'codex' | 'copilot' | 'agy'
export type Mode = 'read-only' | 'write'
export type Effort = 'low' | 'medium' | 'high' | 'xhigh' | 'max'

export type DispatchInput = {
  backend: Backend
  model?: string
  effort?: Effort
  mode: Mode
  prompt: string
  dir?: string
  schema?: string // path to a JSON schema file; the answer must parse as JSON
  resume?: string // session id from an earlier result
  timeoutMs?: number
  ephemeral?: boolean // codex: keep no session (router calls)
  override?: boolean // run even though the backend is at 90 % of a window: only when the user said so
}

export type RouteInput = {
  task: string
  files?: string[]
  instructions?: string
  override?: boolean // the user allows providers at 90 %
}

// What one CLI run's output says.
export type Parsed = {
  ok: boolean
  summary: string // at most SUMMARY_CAP chars, for display
  answer?: string // with a schema: the whole answer, valid JSON
  sessionId: string | null
  error?: string
}

export type DispatchResult = Parsed & {
  attempts: number
  baseTree: string | null // git tree of `dir` before the run; null outside a repo or read-only
  tree: string | null // git tree after the run
  filesChanged: string[] | null // paths that differ between baseTree and tree
  treeError?: string // a git snapshot failed inside a repo (filesChanged is then null)
  quota: ProviderQuota // this backend's quota, read after the run
}

export type XAgent = {
  id: string
  backend: Backend
  model: string
  effort: string
  task: string
  status: 'running' | 'done' | 'failed'
  startedAt: number
  endedAt?: number
  last: string
  quota: string // the backend's quota line when it started
}

export type Window = { usedPercent: number; windowMinutes: number; resetsAt: number | null } // resetsAt: epoch ms, null when unknown
export type ProviderQuota =
  | { state: 'unknown' }
  | { state: 'windows'; windows: Window[] }
  | { state: 'cooldown'; until: number }
  | { state: 'unavailable'; reason: string }
export type Snapshot = { claude: ProviderQuota; codex: ProviderQuota; copilot: ProviderQuota; agy: ProviderQuota }

declare module 'claude-code' {
  interface PluginState {
    xagent: { agents: XAgent[]; effort: string; blocked: Record<string, ProviderQuota> }
  }
  // Written by hand: the generated MCP types only know servers that were connected when they were made.
  interface McpToolInputs {
    mcp__xagent__dispatch: DispatchInput
    mcp__xagent__route: RouteInput
  }
}
```

// Stands for the engine beneath the mod. Every test gets a clock at NOW, a store, HOME,
// and a process.run that answers like a directory outside git unless `run` says otherwise.
import { mock } from 'claude-code/testing'

export const NOW = Date.UTC(2026, 9, 14, 12)
export const START = { surface: 'terminal', isInteractive: true, cwd: '/work' } as any

export type Run = { exitCode: number; stdout: string; stderr: string }

export function engine(on: any, opts: { run?: (argv: string[], env: Record<string, string> | undefined) => Run | undefined; files?: Record<string, string> } = {}) {
  const tools: string[] = []
  const runs: { argv: string[]; cwd?: string; env?: Record<string, string> }[] = []
  // The test Engine has no $.state: xagent's atoms are seen through the writes that pass by.
  const state: Record<string, any> = {}
  on('state.set', { plugin: 'xagent' }, async (_$: any, e: any, next: any) => {
    const r = await next(e)
    if (r.value?.isSet) state[e.key] = e.value
    return r
  })
  const clock = mock.clock(on, { now: NOW })
  mock.store(on)
  mock.env(on, { HOME: '/home/u' })
  const files = opts.files ?? {}
  on('session.start', (_$: any, e: any) => ({ sessionId: 's', cwd: e.cwd }))
  on('tool.register', (_$: any, e: any) => (tools.push(e.name), { value: { tool: `mcp__xagent__${e.name}` } }))
  on('command.register', () => ({ value: undefined }))
  on('session.usage', () => ({ value: { rateLimits: [] } }))
  on('fs.list', () => ({ value: [] }))
  on('fs.exists', (_$: any, e: any) => ({ value: e.path in files }))
  on('fs.read', (_$: any, e: any) => ({ value: files[e.path] ?? '' }))
  on('fs.write', (_$: any, e: any) => ((files[e.path] = e.content ?? e.text ?? ''), { value: undefined }))
  on('process.run', (_$: any, e: any) => {
    // $.process.run(argv, init) arrives as { argv, init }: cwd and env sit under init.
    runs.push({ argv: [...e.argv], cwd: e.init?.cwd, env: e.init?.env })
    return { value: opts.run?.([...e.argv], e.init?.env) ?? { exitCode: 128, stdout: '', stderr: 'fatal: not a git repository' } }
  })
  return { tools, runs, clock, state }
}
```

  properties: {
    backend: { type: 'string', enum: ['codex', 'copilot', 'agy'] },
    model: { type: 'string' },
    effort: { type: 'string', enum: ['low', 'medium', 'high', 'xhigh', 'max'] },

    prompt: { type: 'string' },

    resume: { type: 'string', description: 'sessionId from an earlier dispatch, to continue it' },
    timeoutMs: { type: 'number' },
    override: { type: 'boolean', description: 'run on a backend at 90 % of its quota; only when the user said so' },
  },
  required: ['backend', 'mode', 'prompt'],
}

const ROUTE_SCHEMA_IN = {
  type: 'object',
  properties: {
    task: { type: 'string', description: 'the task text from the plan' },
    files: { type: 'array', items: { type: 'string' } },
    instructions: { type: 'string', description: "the user's standing instructions for this run" },
    override: { type: 'boolean', description: 'the user allows providers at 90 % of their quota' },
  },
  required: ['task'],
}

export const register: Register = on => {
  on('session.start', async ($, e, next) => {
    const r = await next(e)
    await $.tool.register({ name: 'dispatch', description: 'Run one task on an external coding agent (codex, copilot, agy). Returns a short summary, the files it changed and a sessionId for resume.', inputSchema: DISPATCH_SCHEMA }).catch(() => {})

    return r
  })
}

// The command line for one dispatch. No shell: each element is one argv entry.
import type { DispatchInput } from '../types'

const COPILOT_CREDIT_CAP = '30' // the CLI's minimum; one run cannot eat the month

export function buildArgv(i: DispatchInput): string[] {
  if (i.backend === 'codex') {
    // `exec resume` takes no -s or -C, so the sandbox goes through -c and the directory through spawn's cwd.
    const argv = ['codex', 'exec', ...(i.resume ? ['resume'] : []), '--json', '--skip-git-repo-check', '-c', `sandbox_mode="${i.mode === 'write' ? 'workspace-write' : 'read-only'}"`]
    if (i.model) argv.push('-m', i.model)
    if (i.effort) argv.push('-c', `model_reasoning_effort=${i.effort}`)
    if (i.schema) argv.push('--output-schema', i.schema)
    if (i.ephemeral) argv.push('--ephemeral')
    if (i.resume) return [...argv, i.resume, i.prompt]
    if (i.dir) argv.push('-C', i.dir)
    return [...argv, i.prompt]
  }
  if (i.backend === 'copilot') {
    if (i.mode === 'read-only') throw new Error('copilot has no read-only mode')
    const argv = ['copilot', '-p', i.prompt, '--output-format', 'json', '--allow-all-tools']
    if (i.effort) argv.push('--reasoning-effort', i.effort)
    if (i.resume) argv.push('--resume', i.resume)
    return [...argv, '--max-ai-credits', COPILOT_CREDIT_CAP]
  }
  const argv = ['agy', '-p', i.prompt, '--output-format', 'stream-json', '--mode', i.mode === 'write' ? 'accept-edits' : 'plan']
  if (i.model) argv.push('--model', i.model)
  if (i.effort) argv.push('--effort', i.effort)
  if (i.schema) argv.push('--json-schema', i.schema)
  if (i.resume) argv.push('--conversation', i.resume)
  return argv
}
```
The working directory for Copilot, and for Codex on resume, comes from `spawn`'s `cwd` (Task 5).

// Reads each CLI's JSON lines into one result, and one line of status for the radar.
import type { Backend, Parsed } from '../types'

export const SUMMARY_CAP = 4000
export const STRUCTURED_CAP = 200_000
export const KEEP_CAP = 2 * STRUCTURED_CAP // what feed() keeps of a run's stdout

type J = Record<string, any>

function lines(stdout: string): J[] {
  const out: J[] = []
  for (const l of stdout.split('\n')) {
    try {
      const j = JSON.parse(l)
      if (j && typeof j === 'object') out.push(j)
    } catch {}
  }
  return out
}

export function firstLine(text: string, n: number): string {
  return (text.split('\n')[0] ?? '').slice(0, n)
}

function done(answer: string | null, sessionId: string | null, error: string | undefined, structured: boolean): Parsed {
  const summary = (answer ?? '').trim().slice(0, SUMMARY_CAP)
  if (error) return { ok: false, summary, sessionId, error }
  if (answer === null) return { ok: false, summary: '', sessionId, error: 'no answer in output' }
  if (!structured) return { ok: true, summary, sessionId }
  // A schema answer goes back whole: a cut one is not JSON and would break the plan-review loop.
  const whole = answer.trim()
  if (whole.length > STRUCTURED_CAP) return { ok: false, summary, sessionId, error: 'answer too long' }
  try {
    JSON.parse(whole)
  } catch {
    return { ok: false, summary, sessionId, error: 'answer is not valid JSON' }
  }
  return { ok: true, summary, answer: whole, sessionId }
}

export function sessionIdIn(backend: Backend, stdout: string): string | null {
  let id: string | null = null
  for (const j of lines(stdout)) {
    if (backend === 'codex' && j.type === 'thread.started') id = j.thread_id ?? null
    if (backend === 'agy' && j.event === 'init') id = j.conversation_id ?? null
    if (backend === 'copilot' && j.type === 'session.start') id = j.data?.sessionId ?? null
  }
  return id
}

export function parse(backend: Backend, stdout: string, structured: boolean): Parsed {
  let answer: string | null = null
  let error: string | undefined
  const sessionId = sessionIdIn(backend, stdout)
  if (backend === 'codex') {
    for (const j of lines(stdout)) {
      if (j.type === 'item.completed' && j.item?.type === 'agent_message') answer = String(j.item.text ?? '')
      if (j.type === 'turn.failed' || j.type === 'error') error = j.error?.message ?? j.message ?? 'codex failed'
    }
    return done(answer, sessionId, error, structured)
  }
  if (backend === 'agy') {
    let streamed = '' // agy's result.response can be empty after tool use (seen 2026-10-14)
    for (const j of lines(stdout)) {
      if (j.event === 'step_update' && j.step_update?.step_type === 'agent_response') streamed += j.step_update.text_delta ?? ''
      if (j.event === 'result') {
        answer = j.result?.response || streamed
        if (j.result?.status !== 'SUCCESS') error = `agy ${j.result?.status ?? 'failed'}`
      }
    }
    return done(answer, sessionId, error, structured)
  }
  for (const j of lines(stdout)) {
    if (j.type === 'assistant.message' && j.data?.content) answer = String(j.data.content)
    if (j.type === 'session.error') error = j.data?.message ?? 'copilot failed'
  }
  return done(answer, sessionId, error, structured)
}

// The lines parse() and sessionIdIn() read. Command output and reasoning are dropped as they stream.
function wanted(backend: Backend, j: J): boolean {
  if (backend === 'codex') return j.type === 'thread.started' || j.type === 'turn.failed' || j.type === 'error' || (j.type === 'item.completed' && j.item?.type === 'agent_message')
  if (backend === 'agy') return j.event === 'init' || j.event === 'result' || (j.event === 'step_update' && j.step_update?.step_type === 'agent_response')
  return j.type === 'session.start' || j.type === 'assistant.message' || j.type === 'session.error'
}

// Takes stdout as it streams. An event can arrive split across chunks, so lines are put back
// together first. Only wanted lines are kept, within KEEP_CAP: the oldest go first, except the
// first, which carries the session id.
export function feed(backend: Backend) {
  let partial = ''
  let size = 0
  const kept: string[] = []
  const take = (line: string): string | null => {
    let j: J
    try {
      j = JSON.parse(line)
    } catch {
      return null
    }
    if (!j || typeof j !== 'object') return null
    if (wanted(backend, j)) {
      kept.push(line)
      size += line.length + 1
      while (size > KEEP_CAP && kept.length > 1) size -= (kept.splice(1, 1)[0] ?? '').length + 1
    }
    return lastLine(backend, line)
  }
  return {
    // The newest radar status in this chunk, if any.
    push(text: string): string | null {
      const parts = (partial + text).split('\n')
      partial = parts.pop() ?? ''
      if (partial.length > KEEP_CAP) partial = '' // a line that long is never a usable answer
      let status: string | null = null
      for (const l of parts) status = take(l) ?? status
      return status
    },
    // What parse() should read, including a last line that had no newline.
    text(): string {
      if (partial) take(partial)
      partial = ''
      return kept.join('\n')
    },
  }
}

export function lastLine(backend: Backend, line: string): string | null {
  let j: J
  try {
    j = JSON.parse(line)
  } catch {
    return null
  }
  if (backend === 'codex') {
    if (j.item?.type === 'command_execution') return `running ${String(j.item.command).slice(0, 60)}`
    if (j.item?.type === 'file_change') return 'editing files'
    if (j.item?.type === 'agent_message') return 'writing'
    if (j.type === 'turn.started') return 'thinking'
    return null
  }
  if (backend === 'agy') {
    const s = j.step_update
    if (!s) return null
    return s.step_type === 'agent_response' ? 'writing' : String(s.step_type).replace(/_/g, ' ')
  }
  if (j.type === 'assistant.message') return 'writing'
  if (typeof j.type === 'string' && j.type.startsWith('tool.')) return j.type.replace('tool.', 'tool: ')
  return null
}

// Quota per provider: windows of used %, pace against elapsed time, and the 90 % stop.
// A window past its reset and a cooldown past its end are old news: they never block.
import type { ProviderQuota, Snapshot, Window } from '../types'

export const BLOCK_AT = 90
export const COPILOT_MONTHLY_CREDITS = 200
export const NANO_AIU_PER_CREDIT = 1e9 // unverified; Task 11 checks it against copilot /usage
const KIND_MINUTES: Record<string, number> = { five_hour: 300, seven_day: 10080 }

const current = (w: Window, now: number) => w.resetsAt === null || w.resetsAt > now

export function pace(w: Window, now: number): number | null {
  if (w.resetsAt === null || w.resetsAt <= now) return null
  const total = w.windowMinutes * 60_000
  const elapsed = Math.min(Math.max(total - (w.resetsAt - now), 0), total)
  return w.usedPercent - (elapsed / total) * 100
}

export function isBlocked(q: ProviderQuota, now: number): boolean {
  if (q.state === 'unavailable') return true
  if (q.state === 'cooldown') return q.until > now
  if (q.state === 'windows') return q.windows.some(w => current(w, now) && w.usedPercent >= BLOCK_AT)
  return false
}

export function merge(mark: ProviderQuota | undefined, live: ProviderQuota, now: number): ProviderQuota {
  if (mark?.state === 'unavailable') return mark
  if (mark?.state === 'cooldown' && mark.until > now) return mark
  return live
}

export function codexFromRollout(text: string): ProviderQuota {
  let last: any = null
  for (const l of text.split('\n')) {
    if (!l.includes('rate_limits')) continue
    try {
      const j = JSON.parse(l)
      if (j.payload?.rate_limits) last = j.payload.rate_limits
    } catch {}
  }
  if (!last) return { state: 'unknown' }
  const windows: Window[] = [last.primary, last.secondary]
    .filter((w: any) => w && typeof w.used_percent === 'number')
    .map((w: any) => ({ usedPercent: w.used_percent, windowMinutes: w.window_minutes ?? 300, resetsAt: typeof w.resets_at === 'number' ? w.resets_at * 1000 : null }))
  return windows.length ? { state: 'windows', windows } : { state: 'unknown' }
}

export function claudeFromUsage(limits: { kind: string; percentUsed: number; resetsAt?: string }[]): ProviderQuota {
  if (!limits.length) return { state: 'unknown' }
  return {
    state: 'windows',
    windows: limits.map(l => ({ usedPercent: l.percentUsed, windowMinutes: KIND_MINUTES[l.kind] ?? 300, resetsAt: l.resetsAt ? Date.parse(l.resetsAt) : null })),
  }
}

export function copilotMonthStart(now: number): string {
  return `${new Date(now).toISOString().slice(0, 7)}-01 00:00:00`
}

export function copilotFromNanoAiu(nano: number | null, now: number): ProviderQuota {
  if (nano === null) return { state: 'unknown' }
  const d = new Date(now)
  const start = Date.UTC(d.getUTCFullYear(), d.getUTCMonth(), 1)
  const resetsAt = Date.UTC(d.getUTCFullYear(), d.getUTCMonth() + 1, 1)
  const usedPercent = (nano / NANO_AIU_PER_CREDIT / COPILOT_MONTHLY_CREDITS) * 100
  return { state: 'windows', windows: [{ usedPercent, windowMinutes: (resetsAt - start) / 60_000, resetsAt }] }
}

function windowLine(name: string, w: Window, now: number): string {
  if (w.resetsAt !== null && w.resetsAt <= now) return `${name}: ${w.windowMinutes}m window reset passed`
  const p = pace(w, now)
  const lead = p === null ? 'reset time unknown' : p >= 0 ? `${Math.round(p)} ahead of pace` : `${Math.round(-p)} behind pace`
  const resets = w.resetsAt === null ? '' : `, resets in ${Math.round((w.resetsAt - now) / 60_000)}m`
  return `${name}: ${w.windowMinutes}m window ${Math.round(w.usedPercent)}% used, ${lead}${resets}`
}

export function describeOne(name: string, q: ProviderQuota, now: number): string {
  if (q.state === 'unknown') return `${name}: unknown`
  if (q.state === 'unavailable') return `${name}: unavailable (${q.reason})`
  if (q.state === 'cooldown') return q.until > now ? `${name}: cooling down for ${Math.round((q.until - now) / 60_000)}m` : `${name}: unknown`
  return q.windows.map(w => windowLine(name, w, now)).join('\n')
}

const lastErr = (stderr: string) => stderr.trim().split('\n').slice(-1)[0] ?? ''

// The working tree, untracked files included, as a git tree object. A scratch index keeps the
// user's own index untouched. `tree: null` with no error: not a git repo.
export async function treeOf($: EngineInterface, dir?: string): Promise<Tree> {
  if (!dir) return { tree: null }
  const inside = await $.process.run(['git', '-C', dir, 'rev-parse', '--is-inside-work-tree'], { timeoutMs: 10_000 }).catch(() => null)
  if (!inside || inside.exitCode !== 0) return { tree: null }
  const scratch = `${await home($)}/.cache/xagent`
  const index = `${scratch}/index-${await $.clock.now()}-${Math.random().toString(36).slice(2, 8)}`
  try {
    const made = await $.process.run(['mkdir', '-p', scratch], { timeoutMs: 5_000 })
    if (made.exitCode !== 0) return { tree: null, error: `mkdir ${scratch}: ${lastErr(made.stderr)}` }
    const git = (args: string[]) => $.process.run(['git', '-C', dir, ...args], { env: { GIT_INDEX_FILE: index }, timeoutMs: 60_000 })
    if ((await git(['read-tree', 'HEAD'])).exitCode !== 0) {
      const empty = await git(['read-tree', '--empty']) // a repo with no commits yet
      if (empty.exitCode !== 0) return { tree: null, error: `git read-tree: ${lastErr(empty.stderr)}` }
    }
    const added = await git(['add', '-A'])
    if (added.exitCode !== 0) return { tree: null, error: `git add: ${lastErr(added.stderr)}` }
    const tree = await git(['write-tree'])
    if (tree.exitCode !== 0 || !tree.stdout.trim()) return { tree: null, error: `git write-tree: ${lastErr(tree.stderr)}` }
    return { tree: tree.stdout.trim() }
  } catch (err) {
    return { tree: null, error: (err as Error).message }
  } finally {
    await $.process.run(['rm', '-f', index], { timeoutMs: 5_000 }).catch(() => null)
  }
}

// NUL-separated names, so paths with spaces or non-ASCII come back as they are.
export async function changedFiles($: EngineInterface, dir: string, a: string, b: string): Promise<{ files: string[] } | { error: string }> {
  const r = await $.process.run(['git', '-C', dir, 'diff', '--name-only', '-z', a, b], { timeoutMs: 30_000 }).catch(() => null)
  if (!r || r.exitCode !== 0) return { error: `git diff: ${lastErr(r?.stderr ?? 'did not run')}` }
  if (r.isStdoutTruncated) return { error: 'git diff: file list too long' }
  return { files: r.stdout.split('\0').filter(Boolean) }
}

// The rollout written most recently (a resumed old session counts), read from its end: the first
// rate_limits sample found is the newest. Up to three files, for one with no sample yet.
async function codexQuota($: EngineInterface) {
  const sessions = `${await home($)}/.codex/sessions`
  const found = await $.process.run(['find', sessions, '-name', 'rollout-*.jsonl', '-mtime', '-8', '-printf', '%T@ %p\\n'], { timeoutMs: 10_000 }).catch(() => null)
  if (!found || found.exitCode !== 0) return codexFromRollout('')
  const newest = found.stdout
    .split('\n')
    .map(l => /^(\S+) (.+)$/.exec(l))
    .flatMap(m => (m?.[1] && m[2] ? [{ at: Number(m[1]), path: m[2] }] : []))
    .sort((x, y) => y.at - x.at)
    .slice(0, 3)
  for (const f of newest) {
    // tac puts the end first; process.run keeps the first 4 MB, so that is the file's last 4 MB.
    const r = await $.process.run(['tac', f.path], { timeoutMs: 10_000 }).catch(() => null)
    if (!r || r.exitCode !== 0) continue
    const q = codexFromRollout(r.stdout.split('\n').reverse().join('\n'))
    if (q.state !== 'unknown') return q
  }
  return codexFromRollout('')
}

  if (!r || r.exitCode !== 0) return null
  const n = Number(r.stdout.trim())
  return Number.isFinite(n) ? n : null
}

// Ends the child through its stream (leaving the loop kills it) and says whether that is
// confirmed: stop() resolved within the grace period. A rejected or hanging stop() is not.
export async function stopStream(stop: () => Promise<unknown>, sleep: () => Promise<void>): Promise<boolean> {
  const ended = stop().then(() => true, () => false)
  return Promise.race([ended, sleep().then(() => false)])
}

async function mark($: EngineInterface, backend: string, q: ProviderQuota) {
  await update($, blocked, all => ({ ...all, [backend]: q }))
}

async function track($: EngineInterface, id: string, patch: Partial<XAgent>) {
  await update($, agents, list => list.map(a => (a.id === id ? { ...a, ...patch } : a)))
}

// One CLI run. `stopped` is false only when a child we had to stop was not confirmed gone.
async function runOnce($: EngineInterface, input: DispatchInput, argv: string[], id: string): Promise<Parsed & { stopped: boolean }> {
  const out = feed(input.backend)
  let stderr = ''
  let failure: string | undefined
  let end: { code: number | null; signal: string | null } = { code: null, signal: null }
  let stopped = true
  let pulling = false
  // spawn closes stdin from the start (no `input`): codex exec otherwise waits on it.
  const stream = $.process.spawn({ argv, cwd: input.dir })
  const stop = () => stream.return({ code: null, signal: null })
  const grace = () => $.clock.sleep(STOP_GRACE_MS)
  // Wall clock, raced against each pull: a child that prints nothing must still stop.
  let ring: () => void = () => {}
  const expired = new Promise<'expired'>(resolve => (ring = () => resolve('expired')))
  const timer = $.clock.after(input.timeoutMs ?? DEFAULT_TIMEOUT_MS, () => ring())
  try {
    while (true) {
      pulling = true
      const step = await Promise.race([stream.next(), expired])
      pulling = false
      if (step === 'expired') {
        stopped = await stopStream(stop, grace)
        failure = stopped ? 'timed out' : 'timed out (child may still be running)'
        break
      }
      if (step.done) {
        end = step.value ?? end
        break
      }
      const piece = step.value
      if (piece.stream === 'stderr') {
        stderr = (stderr + piece.text).slice(-2000)
        continue
      }
      const status = out.push(piece.text)
      if (status) await track($, id, { last: status })
    }
  } catch (err) {
    failure ??= (err as Error).message
    // A failed pull means the child never started or already ended. A failure in our own code
    // between pulls leaves it running, so stop it.
    if (!pulling) stopped = await stopStream(stop, grace)
  } finally {
    timer.cancel()
  }
  const stdout = out.text()
  const sessionId = sessionIdIn(input.backend, stdout)
  if (failure) return { ok: false, summary: '', sessionId, error: failure, stopped }
  const result = parse(input.backend, stdout, Boolean(input.schema))
  const why = stderr.trim().split('\n').slice(-3).join(' ').slice(0, 300)
  // The CLI's own error (a usage limit, say) says more than stderr or the exit code.
  const said = !result.ok && result.error !== 'no answer in output' ? result.error : undefined
  // An answer only counts from a child that ended cleanly.
  if (end.signal) return { ...result, ok: false, error: said ?? `killed by ${end.signal}`, stopped }
  if (end.code !== 0) return { ...result, ok: false, error: said ?? (!result.ok && why ? why : `exited with code ${end.code}`), stopped }
  if (!result.ok && result.error === 'no answer in output' && why) return { ...result, error: why, stopped }
  return { ...result, stopped }
}

export async function runDispatch($: EngineInterface, raw: DispatchInput, task: string): Promise<DispatchResult> {
  const home = (await $.env.get('HOME')) ?? ''
  const input: DispatchInput = { ...raw, dir: raw.dir && expandHome(raw.dir, home), schema: raw.schema && expandHome(raw.schema, home) }
  let argv: string[]
  try {
    argv = buildArgv(input)
  } catch (err) {
    const q = (await snapshot($))[input.backend]
    return { ok: false, summary: '', sessionId: null, error: (err as Error).message, attempts: 0, baseTree: null, tree: null, filesChanged: null, quota: q }
  }
  const startedAt = await $.clock.now()
  const before = (await snapshot($))[input.backend]
  const refuse = (error: string, extra: Partial<DispatchResult> = {}): DispatchResult => ({ ok: false, summary: '', sessionId: null, error, attempts: 0, baseTree: null, tree: null, filesChanged: null, quota: before, ...extra })
  // The 90 % rule: no new work for a provider that close to a limit, unless the user said so.
  if (!input.override && isBlocked(before, startedAt)) return refuse(`${input.backend} is at 90 % of a quota window: ask the user, or pass override if they allow it`)
  // A writer may only start once its baseline is known: a lost baseline cannot be taken back after edits.
  const base = input.mode === 'write' ? await treeOf($, input.dir) : { tree: null }
  if (base.error) return refuse(`baseline snapshot failed: ${base.error}`, { treeError: base.error })
  const id = `x${startedAt.toString(36)}${Math.random().toString(36).slice(2, 6)}`
  const quotaLine = describeOne(input.backend, before, startedAt).split('\n')[0] ?? ''
  const one: XAgent = { id, backend: input.backend, model: input.model ?? 'default', effort: input.effort ?? 'default', task, status: 'running', startedAt, last: 'starting', quota: quotaLine }
  await update($, agents, list => [one, ...list].slice(0, 30))

  let attempts = 1
  let result = await runOnce($, input, argv, id)
  // One retry, owned here (the skill never retries): only once the first child is known to be gone.
  if (result.error === 'timed out' && result.stopped) {
    attempts = 2
    await track($, id, { last: 'timed out; retrying' })
    const again: DispatchInput = result.sessionId ? { ...input, resume: result.sessionId, prompt: RETRY_PROMPT } : input
    result = await runOnce($, again, buildArgv(again), id)
  }

  const now = await $.clock.now()
  if (!result.ok) {
    const why = result.error ?? ''
    if (AUTH_WORDS.test(why)) await mark($, input.backend, { state: 'unavailable', reason: why.slice(0, 80) })
    else if (LIMIT_WORDS.test(why)) await mark($, input.backend, { state: 'cooldown', until: now + COOLDOWN_MS })
  }
  const after = base.tree ? await treeOf($, input.dir) : { tree: null }
  const diff = base.tree && after.tree && input.dir ? await changedFiles($, input.dir, base.tree, after.tree) : null
  const treeError = after.error ?? (diff && 'error' in diff ? diff.error : undefined)
  const quota = (await snapshot($))[input.backend]
  await track($, id, { status: result.ok ? 'done' : 'failed', endedAt: now, last: result.ok ? 'finished' : `stopped: ${result.error}` })
  const { stopped: _, ...parsed } = result
  return {
    ...parsed,
    attempts,
    baseTree: base.tree,
    tree: after.tree,
    filesChanged: diff && 'files' in diff ? diff.files : null,
    quota,
    ...(treeError ? { treeError } : {}),
  }
}

// The routing policy: orchestrator effort sets a band, complexity picks inside it, quota breaks
// ties. The router model proposes; clamp() keeps the proposal inside the band. routing.md's
// json block can change the router and the bands; its prose only informs the router.
import type { Backend, Effort, Snapshot } from '../types'
import { isBlocked } from './quota'

export type Pick = {
  complexity: 'trivial' | 'standard' | 'hard'
  implementer: { backend: Backend; model: string; effort: Effort }
  reviewer: { model: 'sonnet' | 'haiku'; effort: Effort }
  reviewDepth: 'spec' | 'spec+quality' | 'adversarial'
  secondSolReview: boolean
  wait: string | null // set: the task must not start; the skill asks the user
  why: string
}

export type Band = { impl: [Effort, Effort]; review: [Effort, Effort]; haiku: boolean }
export type RoutingConfig = { router: { backend: Backend; model: string; effort: Effort }; bands: Record<Effort, Band> }

const ORDER: Effort[] = ['low', 'medium', 'high', 'xhigh', 'max']
const BACKENDS: Backend[] = ['codex', 'copilot', 'agy']
const ROUTERS: Backend[] = ['codex', 'agy'] // the router runs read-only; copilot has no read-only mode
const COMPLEXITY: Pick['complexity'][] = ['trivial', 'standard', 'hard']
const DEPTHS: Pick['reviewDepth'][] = ['spec', 'spec+quality', 'adversarial']
const REVIEWERS: Pick['reviewer']['model'][] = ['sonnet', 'haiku']

const isEffort = (x: unknown): x is Effort => ORDER.includes(x as Effort)
const rank = (e: string) => Math.max(0, ORDER.indexOf(e as Effort))
const within = (e: Effort, [lo, hi]: [Effort, Effort]): Effort => ORDER[Math.min(Math.max(rank(e), rank(lo)), rank(hi))] ?? lo

const LOW: Band = { impl: ['low', 'medium'], review: ['low', 'medium'], haiku: true }
const HIGH: Band = { impl: ['medium', 'high'], review: ['medium', 'max'], haiku: false }
const TOP: Band = { impl: ['high', 'xhigh'], review: ['high', 'max'], haiku: false }

export const DEFAULT_CONFIG: RoutingConfig = {
  router: { backend: 'codex', model: 'gpt-6-luna', effort: 'low' },
  bands: { low: LOW, medium: LOW, high: HIGH, xhigh: TOP, max: TOP },
}

// A [low, high] effort range, low first.
function isRange(r: unknown): r is [Effort, Effort] {
  return Array.isArray(r) && r.length === 2 && isEffort(r[0]) && isEffort(r[1]) && rank(r[0]) <= rank(r[1])
}

function isBand(b: any): b is Band {
  return b && isRange(b.impl) && isRange(b.review) && typeof b.haiku === 'boolean'
}

export function readConfig(markdown: string): { config: RoutingConfig; note: string | null } {
  const block = /```json\n([\s\S]*?)\n```/.exec(markdown)?.[1]
  if (!block) return { config: DEFAULT_CONFIG, note: null }
  try {
    const j = JSON.parse(block)
    const router = j.router ?? DEFAULT_CONFIG.router
    if (!ROUTERS.includes(router.backend) || typeof router.model !== 'string' || !router.model || !isEffort(router.effort)) throw new Error('router')
    const bands = { ...DEFAULT_CONFIG.bands }
    for (const [k, b] of Object.entries(j.bands ?? {})) {
      if (!isEffort(k) || !isBand(b)) throw new Error(`band ${k}`)
      bands[k] = b
    }
    return { config: { router, bands }, note: null }
  } catch (err) {
    return { config: DEFAULT_CONFIG, note: `routing.md config invalid (${(err as Error).message}); defaults` }
  }
}

export function bandFor(orchestrator: string, c: RoutingConfig): Band {
  return c.bands[isEffort(orchestrator) ? orchestrator : 'medium']
}

// Fallback implementers when the preferred backend is blocked, in order.
const FALLBACK: { backend: Backend; model: string }[] = [
  { backend: 'codex', model: 'gpt-6.1-sol' },
  { backend: 'agy', model: 'gemini-3.8-flash-high' },
  { backend: 'copilot', model: 'auto' },
]

export function defaults(orchestrator: string, c: RoutingConfig, complexity: Pick['complexity'] = 'standard'): Pick {
  const b = bandFor(orchestrator, c)
  return {
    complexity,
    implementer: { backend: 'codex', model: 'gpt-6.1-sol', effort: complexity === 'hard' ? b.impl[1] : b.impl[0] },
    reviewer: { model: b.haiku && complexity === 'trivial' ? 'haiku' : 'sonnet', effort: b.review[0] },
    reviewDepth: complexity === 'trivial' ? 'spec' : complexity === 'hard' ? 'adversarial' : 'spec+quality',
    secondSolReview: false,
    wait: null,
    why: 'defaults',
  }
}

// Keeps a pick inside the band and applies the 90 % rule. `override`: the user allows providers
// at 90 %, so the pick stands as it is.
export function clamp(p: Pick, orchestrator: string, snap: Snapshot, now: number, c: RoutingConfig, override = false): Pick {
  const b = bandFor(orchestrator, c)
  const notes: string[] = []
  const waits: string[] = []
  const blocked = (backend: keyof Snapshot) => !override && isBlocked(snap[backend], now)
  let implementer = { ...p.implementer, effort: within(p.implementer.effort, b.impl) }
  if (blocked(implementer.backend)) {
    notes.push(`${implementer.backend} blocked`)
    const open = FALLBACK.find(f => f.backend !== implementer.backend && !blocked(f.backend))
    if (open) implementer = { ...open, effort: implementer.effort }
    else waits.push(`every implementer is at 90 % or unavailable (${[implementer.backend, ...FALLBACK.map(f => f.backend).filter(x => x !== implementer.backend)].join(', ')})`)
  }
  if (implementer.backend === 'copilot') implementer = { ...implementer, model: 'auto' } // Student plan: auto only
  const reviewer = { model: p.reviewer.model === 'haiku' && !b.haiku ? ('sonnet' as const) : p.reviewer.model, effort: within(p.reviewer.effort, b.review) }
  if (blocked('claude')) waits.push('claude is at 90 %: the reviewer cannot run')
  // A required second Sol review is never dropped: with codex at 90 % the task waits.
  const secondSolReview = rank(orchestrator) >= 3 && p.complexity === 'hard'
  if (secondSolReview && blocked('codex')) waits.push('codex is at 90 %: the second Sol review cannot run')
  if (override) notes.push('user override: 90 % rule off')
  return { ...p, implementer, reviewer, secondSolReview, wait: waits.length ? waits.join('; ') : null, why: [p.why, ...notes].join('; ') }
}

export const ROUTE_SCHEMA = {
  type: 'object',
  additionalProperties: false,
  required: ['complexity', 'implementer', 'reviewer', 'reviewDepth', 'why'],
  properties: {
    complexity: { enum: COMPLEXITY },
    implementer: {
      type: 'object', additionalProperties: false, required: ['backend', 'model', 'effort'],
      properties: { backend: { enum: BACKENDS }, model: { type: 'string' }, effort: { enum: ORDER } },
    },
    reviewer: {
      type: 'object', additionalProperties: false, required: ['model', 'effort'],
      properties: { model: { enum: REVIEWERS }, effort: { enum: ORDER } },
    },
    reviewDepth: { enum: DEPTHS },
    why: { type: 'string' },
  },
}

export function routerPrompt(task: string, files: string[], orchestrator: string, quota: string, routing: string, instructions: string): string {
  return [
    'You route one coding task to models. Answer only with JSON matching the schema. You have no repository; judge from the text below.',
    'Rate complexity from the task alone. Prefer the cheapest pick that fits; move work away from providers ahead of pace and toward ones behind pace near reset.',
    `Orchestrator effort: ${orchestrator}`,
    `Quota now:\n${quota}`,
    routing ? `Routing table:\n${routing}` : '',
    instructions ? `User instructions (these win):\n${instructions}` : '',
    `Files: ${files.join(', ') || 'not listed'}`,
    `Task:\n${task}`,
  ].filter(Boolean).join('\n\n')
}

// The router's answer, checked field by field; anything off falls back to the band defaults.
export function parsePick(text: string, orchestrator: string, c: RoutingConfig): Pick {
  try {
    const j = JSON.parse(text)
    const ok =
      COMPLEXITY.includes(j.complexity) &&
      BACKENDS.includes(j.implementer?.backend) &&
      typeof j.implementer?.model === 'string' && j.implementer.model.length > 0 &&
      isEffort(j.implementer?.effort) &&
      REVIEWERS.includes(j.reviewer?.model) &&
      isEffort(j.reviewer?.effort) &&
      DEPTHS.includes(j.reviewDepth) &&
      typeof j.why === 'string'
    if (!ok) throw new Error('fields')
    return {
      complexity: j.complexity,
      implementer: { backend: j.implementer.backend, model: j.implementer.model, effort: j.implementer.effort },
      reviewer: { model: j.reviewer.model, effort: j.reviewer.effort },
      reviewDepth: j.reviewDepth,
      secondSolReview: false,
      wait: null,
      why: j.why,
    }
  } catch {
    return { ...defaults(orchestrator, c), why: 'router output unusable; defaults' }
  }
}
